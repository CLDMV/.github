# v4.8.8 — 2026-05-27

Patch release that makes the coverage jobs build the package before type-checking, plus a docs correction.

## Fixed

- **Coverage legs build before type-check.** The coverage-badge and coverage-pr-comment reusable workflows run on a fresh runner, so the `dist/` produced by the sibling matrix build was not available and `test:types` failed (TS2307) for packages whose types resolve against compiled output. Both workflows gained a Build step with new `build_command` (default `npm run build:ci`) and `skip_build` inputs, and `workflow-ci.yml` forwards them (with a new `skip_build` input of its own) so repos with no build can opt out. ([#85](https://github.com/CLDMV/.github/pull/85))

## Changed

- **Branch-naming docs describe the paths-gate.** The branch-naming convention doc now states that docs branches are green-lit by the `paths-gate` instead of a trigger-level `paths-ignore`. ([#84](https://github.com/CLDMV/.github/pull/84))
