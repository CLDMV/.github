# v4.39.4 — 2026-11-19

Patch release: the runner image ships the node-gyp headers for its Node version, so parallel native builds stop racing on them, and bootstrap no longer checks private vulnerability reporting on private repos.

## Bug Fixes

- **Native builds racing on node-gyp headers.** Every native build in a CI job or k3s-test pod downloaded the Node headers into the shared `~/.cache/node-gyp/<version>`. With two packages building at once (pnpm runs install scripts in parallel, e.g. node-pty and cpu-features), the second extract left `common.gypi` newer than the first package's Makefile. make then took its "Regenerating Makefile" rule, which runs `gyp_main.py` directly, and that file is 644 in the node-gyp tarball: `Permission denied`. The image now installs the headers for its Node at build time and checks that `common.gypi` is there, so node-gyp skips the download. A job that switches Node with setup-node still downloads headers for that version. ([#508](https://github.com/CLDMV/.github/pull/508))

- **Private vulnerability reporting on private repos.** The feature only exists on public repos, but bootstrap checked it everywhere and, on the 404, pointed at a settings toggle a private repo doesn't have. Bootstrap now skips the check on private repos with a one-line note, and keeps the hint for public repos. Fixes [#506](https://github.com/CLDMV/.github/issues/506). ([#507](https://github.com/CLDMV/.github/pull/507))

## Upgrade notes

- No caller changes. The runner image rebuilds when this release reaches master.
