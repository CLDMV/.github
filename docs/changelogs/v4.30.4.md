# v4.30.4 — 2026-10-02

Patch release that finishes the v4.30.3 fix: the in-repo PR mirror job now runs instead of skipping, so its check name renders properly.

## Fixed

- **The in-repo PR mirror job runs as a no-op instead of skipping.** GitHub never evaluates the `name:` of a skipped job, so after v4.30.3 every in-repo PR showed the raw expression as a check name. The mirror job in the `ci.yml` template and `local-ci.yml` now uses `if: always()` and never skips. On the in-repo PR path it runs under `⏭️ Required PR Check (reported by the push run)` and exits successfully without gating anything, while the push run still posts `✅ Required PR Check`. Every path that posts the required name still waits on the full test matrix through `needs`. ([#351](https://github.com/CLDMV/.github/pull/351), fixes [#350](https://github.com/CLDMV/.github/issues/350))
