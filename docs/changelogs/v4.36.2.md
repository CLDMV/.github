# v4.36.2 — 2026-11-13

Patch release that makes `sync-release-notes` actually rewrite merged release PR bodies, which v4.36.1 added but never did. On llm-translator the first sync updated every Release page, but release PR CLDMV/llm-translator#149 kept its relative links.

## Bug Fixes

- **Merged release PRs are found again.** The step looks up a release's PR with `GET /commits/{sha}/pulls` and matched it on `merge_commit_sha`. For the bot token that listing came back without the field, so no PR ever matched and none was rewritten, with nothing reported. A merged PR into the default branch whose listing has no `merge_commit_sha` is now confirmed on the full PR (`GET /pulls/{n}`) before its links are pointed at the tag. ([#461](https://github.com/CLDMV/.github/pull/461))
- **Release PR column in the summary.** Each version's row now shows its release PR and what happens to it: would update, updated, up to date, or not found. ([#461](https://github.com/CLDMV/.github/pull/461))
- **No more API response dumps.** The shared API helper logs every response body by default, which printed release and PR JSON above the summary. The sync step now keeps that output for runs with Actions debug logging on. ([#461](https://github.com/CLDMV/.github/pull/461))

## Upgrade notes

- No caller changes needed. Repos that already ran `sync-release-notes` on v4.36.1 should run it again: release bodies are already done and stay as they are, and this run rewrites the release PR bodies.
