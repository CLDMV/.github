# v4.3.1 — 2026-05-25

Patch release so branch retention runs when pull requests close against the v4 integration branches.

## Fixed

- **Branch retention fires on PR-close against `next` and `hotfixes`.** `local-branch-retention.yml` did not trigger for PRs closing against the v4 integration branches, so merged feature-branch heads were not cleaned up. The trigger and the `branch-retention.yml` consumer template were updated, and the branch-naming and release-flow-v4 conventions docs describe the behavior. ([#34](https://github.com/CLDMV/.github/pull/34), released in [#35](https://github.com/CLDMV/.github/pull/35))
