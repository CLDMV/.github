# v4.4.0 — 2026-05-26

Minor release introducing the Dependabot-security → hotfix-lane redirector, plus a broad set of release-PR changelog fixes and CLA central-ledger override support.

## Added

- **Dependabot security updates are redirected to the hotfix lane.** `redirect-hotfix-pr` detects a Dependabot security PR and reroutes it to `hotfixes`, so security fixes ship through the hotfix lane instead of pooling on `next` with routine feature work. (feat: c4e4c89)

## Changed

- **Per-branch merge methods on the integration branches.** `next` / `hotfixes` prefer a merge commit (with squash as a fallback), and stacked-PR commits are deduped in the release-PR changelog. (fix: c552494, 29637d7)
- **CLA override support.** The bot reads the CLA from the central ledger by default, or from a consumer override, scoped per text-hash; the audit tool walks both the default and override signature trees. The root `CLA.md` is removed — the central ledger is the single source. (fix: 132bcb7, 84ecbed, f01b007)
- **v4-tuned `dependabot.yml` template** added, with the auto-merge wiring updated to match. (chore: d52b60e)

## Fixed

- **Release-PR changelogs drop merge commits** and annotate each entry with its source-PR reference, so the generated changelog reads as a clean per-PR summary. (fix: 7ccdfde, 29637d7)
- **Copilot review moved to `next` / `hotfixes`** in the rulesets, allowing squash as a fallback merge method. (fix: 26dcea8)
- **CodeQL "missing regular expression anchor"** finding resolved. (fix: 329f7fe)

## Migration note

Consumers adopting the Dependabot-security redirect need the `hotfix-redirector` workflow installed and a `hotfixes` branch (v4-adopted repos). See `examples/individual-repo-workflows/release-flow-v4/`.
