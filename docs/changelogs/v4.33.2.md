# v4.33.2 — 2026-10-12

Patch release so the tag-health jobs run again on a repository whose release tags carry changelog-sized messages.

## Fixed

- **Update Major Version Tags no longer fails with `Argument list too long`.** Release tag messages have been whole changelogs since v4.31, and `get-detailed-tags` emitted the full message of up to 100 tags inside one JSON value that the later steps receive as an action input. That value exceeded the kernel's per-argument limit, so every job after the first step failed on the v4.33.1 release: Update Major/Minor Tags, Fix Bot Signatures, Fix Unsigned Tags, Fix Misaligned Major/Minor Tags and Fix Orphaned Tags. `get-detailed-tags` no longer includes the message. `fix-unsigned-tags`, `fix-non-bot-tags` and `fix-orphaned-tags` read the one message they rewrite with the new `readTagMessage()` helper, which keeps `#` headings and blank lines, leaves out the PGP signature block, and falls back to the tag name for a lightweight or missing tag. Re-signed tags also keep their blank lines now, which the old extraction dropped. ([#385](https://github.com/CLDMV/.github/pull/385))
