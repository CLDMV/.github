# v4.8.3 — 2026-05-26

Patch release correcting a secret name in a consumer template.

## Fixed

- **`update-major-version-tags.yml` template uses the `BOT_APP_CLIENT_ID` secret name.** The core-cicd template referenced a differently named secret, so consumers copying it would not get the bot app token. The template now uses `BOT_APP_CLIENT_ID`. ([#73](https://github.com/CLDMV/.github/pull/73), released in [#74](https://github.com/CLDMV/.github/pull/74))
