# v4.8.2 — 2026-05-26

Patch release fixing `advanced_security` handling in org bootstrap on public repositories.

## Fixed

- **`advanced_security` is only patched when the API exposes the field.** Sending it for public repositories returned HTTP 422, which failed the bootstrap run. `org-bootstrap-repo` now skips the field on public repos and only issues the `PATCH` when the repository's API response includes it. ([#70](https://github.com/CLDMV/.github/pull/70), [#72](https://github.com/CLDMV/.github/pull/72), released in [#71](https://github.com/CLDMV/.github/pull/71))
