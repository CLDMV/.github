# v4.30.6 — 2026-10-03

Patch release so a broken build on the base branch no longer fails the bundle-size check of a PR that cannot fix it.

## Fixed

- **Bundle size falls back to an empty baseline when the base build fails.** The base is code that has already landed, for example a pre-onboarding `master` whose build script points at something that no longer exists, so a PR has no way to repair it. When the base build command fails, `reusable-bundle-size.yml` now logs a warning and records an empty baseline. The head build is still measured and still fails the run if it breaks. ([#357](https://github.com/CLDMV/.github/pull/357))
