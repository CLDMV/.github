# v4.33.5 — 2026-10-25

Documentation-only patch that extends the library package layout convention for libraries built on slothlet. No workflow, action or template changed.

## Documentation

- **Convention addition: libraries built on slothlet.** [`docs/conventions/package-layout.md`](https://github.com/CLDMV/.github/blob/master/docs/conventions/package-layout.md) gains a "Libraries built on slothlet" section for packages that compose their own API with `slothlet({ base: <dir>/api })`. Slothlet scans the `api/` folder at runtime and derives endpoint names from the file tree, so a single tsup bundle breaks discovery; these libraries publish a `dist/` that mirrors `src/` file by file (`entry: ["src/**/*.mjs"]`, `bundle: false`). The section also covers keeping helpers in `src/lib/` outside the api, copying `src/index.cjs` verbatim in `onSuccess`, why the `../devcheck.mjs` import keeps working without bundling, avoiding top-level `await` in anything `index.mjs` imports, making `test:dist` compose the built `dist/api` through slothlet, loading leaves through Vite's module graph so coverage attributes, and following slothlet's engines floor (`>=22.15.0` for slothlet 3.x) in `package.json` and in the `min_node_version` input of both `ci.yml` and `publish.yml`. `CLDMV/llm-translator` is the reference implementation. ([#394](https://github.com/CLDMV/.github/pull/394))
