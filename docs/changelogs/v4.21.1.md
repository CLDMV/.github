# v4.21.1 — 2026-08-09

Patch release baking the Node.js LTS runtime into the self-hosted runner image.

## Fixed

- **The `cldmv-runners` image includes Node.js.** The image previously carried only `gh` and `jq`, so run steps invoking `node` or `npm` directly failed on self-hosted runners, unlike GitHub-hosted ones. The Dockerfile now installs the current LTS from the NodeSource `lts` channel (including npm and npx), so the weekly rebuild tracks LTS promotions, and the build fails if `gh`, `jq`, `node` or `npm` is missing. Jobs that need a specific version still use `actions/setup-node`. ([#228](https://github.com/CLDMV/.github/pull/228))
