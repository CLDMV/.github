# v4.18.0 — 2026-08-02

Minor release turning the dependency-review PR comment from bare counts into a real report, followed by a patch line hardening the release-base resolution and shipping the first CodeQL skip escape hatch.

## Changed

- **Dependency-review PR comment posts the full report, packages named per category.** The action's own comment only showed counts ("3 packages with unknown licenses" — which ones?). The reusable now suppresses it and composes its own upserted comment from the action's structured outputs, listing the actual packages under each count: vulnerable (with worst severity + advisory id), incompatible/invalid/unknown licenses, denied, and OpenSSF-Scorecard-below-threshold (resolved via the Scorecard API since the action doesn't output it). (#179, compacted in #181)
