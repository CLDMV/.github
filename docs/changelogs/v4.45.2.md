# v4.45.2 — 2026-11-25

Patch release: the Commit Subjects check covers every branch's pushes, not just feature branches, and the org-onboarding template no longer drops repos past the 256-job matrix cap.

## Bug Fixes

- **Commit Subjects checks every branch.** The check from v4.42.0 only covered captured feature branches and fork PRs, so commits pushed to `dev` on dev-trunk repos, direct commits to `next` or `hotfixes` (a fix for a review on the release PR), and Copilot's `Initial plan` commits on `copilot/*` reached the release range unchecked. A push to any branch other than the default branch, `master`/`main`, `badges`, `gh-pages` and `dependabot/*` now has the commits it added (`compare before...after`) checked; feature branches keep the full `base...branch` compare. A new branch is compared against `next`, except a new `dev`, `next` or `hotfixes`, which is skipped. A force-push is skipped, with a warning except on `next` and `hotfixes`, which every release resets. PR merges into `next` still pass, because merge commits are exempt and the PR's commits were checked on its branch. Fixes [#557](https://github.com/CLDMV/.github/issues/557) ([#558](https://github.com/CLDMV/.github/pull/558)), fixes [#560](https://github.com/CLDMV/.github/issues/560) ([#561](https://github.com/CLDMV/.github/pull/561))
- **org-onboarding template past 256 repos.** `examples/individual-repo-workflows/packaging-docs/org-onboarding.yml` cut an auto-discovered repo list at 256 with only a warning, so a larger org never onboarded the end of the alphabet. The list is now split across two matrix jobs, the second running after the first so the `concurrency` input still caps the run, and a list over 512 fails the run instead of truncating. Fixes [#562](https://github.com/CLDMV/.github/issues/562) ([#563](https://github.com/CLDMV/.github/pull/563))

## Upgrade notes

- No caller changes for the commit check. A Copilot branch now fails CI until its `Initial plan` commits are reworded, and a direct non-conventional commit to `next` or `hotfixes` fails that push's CI.
- Re-sync a private org-onboarding copy from the template to pick up the batching.
