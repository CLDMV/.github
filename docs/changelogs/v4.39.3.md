# v4.39.3 — 2026-11-19

Patch release: tag-health now re-signs tags whose signature is glued onto the last message line, including the v4.39.2 tags themselves.

## Bug Fixes

- **Glued tag signatures counted as signed.** Tags written before the v4.39.2 newline fix carry `-----BEGIN PGP SIGNATURE-----` on the same line as the end of the message. `git verify-tag` and GitHub treat them as unsigned, but the signed check only looked for the string anywhere in the tag, so tag-health skipped them. A new `hasTagSignature()` helper requires the armor header on its own line, and both `get-detailed-tags` and `getTagInfo` use it. v4.39.2's own tags were cut by the release run before `@v4` moved to the fix, so they are glued too. ([#501](https://github.com/CLDMV/.github/pull/501))

## Upgrade notes

- No caller changes. The next tag-health run in each repo re-signs the affected tags.
