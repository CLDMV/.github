# v4.39.1 — 2026-11-18

Patch release that finishes the v4.37.1 first-release fix: a default branch with no `package.json` at all no longer makes `next` re-bump on every push.

## Bug Fixes

- **First releases on repos with no `package.json` on the default branch.** v4.37.1 treated a `package.json` with no `version` field as base 0.0.0, but a default branch with no `package.json` still read as an unknown base. That skips the already-bumped check, so every push to `next` bumped again (github-platform went from 0.1.0 to 0.2.0 after its changelog PR merged, and the release PR then asked for a v0.2.0 changelog). A missing file is now base 0.0.0 as well. The release-PR opener's copy of the same lookup now shares the helper. ([#492](https://github.com/CLDMV/.github/pull/492), fixes [#491](https://github.com/CLDMV/.github/issues/491))

## Upgrade notes

- No caller changes. A repo that already re-bumped corrects itself on the next Next Release run: `check-release-commit` sees that the version it expects was bumped earlier but `package.json` has moved past it, and bumps back.
