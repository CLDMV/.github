# v4.14.4 — 2026-06-16

Patch release making Dependabot auto-merge work on merge-only branches.

## Fixed

- **Auto-merge picks a merge method the target branch allows.** The `merge_method` input now defaults to `merge` instead of `squash`, matching the merge-only rulesets on `next` and `hotfixes`, and the action reads the branch's allowed merge methods and falls back to a permitted one when the configured method is rejected. ([#131](https://github.com/CLDMV/.github/pull/131), released in [#132](https://github.com/CLDMV/.github/pull/132))
- **Already-mergeable PRs are merged directly.** When GitHub refuses to queue auto-merge because the PR is already in a clean or unstable state, the action now falls back to a direct merge. The merge endpoint still enforces required checks, and any other auto-merge failure still surfaces as an error. ([#131](https://github.com/CLDMV/.github/pull/131), released in [#132](https://github.com/CLDMV/.github/pull/132))
