# v4.8.7 — 2026-05-27

Patch release that fixes the Local CI `paths-gate` job introduced in v4.8.6, which could not resolve its local action.

## Fixed

- **Local CI checks out the repository before using the relative `paths-gate` action.** The `paths-gate` job referenced `./.github/actions/common/steps/paths-gate` without a prior checkout, so the action's `action.yml` could not be found. A checkout step was added ahead of it. ([#82](https://github.com/CLDMV/.github/pull/82))
