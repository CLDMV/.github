# v4.17.0 — 2026-07-31

Minor release unsticking Dependabot's edited-PR dead-end and giving dependency bumps their own branch lane.

## Added

- **Auto-recreate Dependabot PRs stuck in the edited-by-non-dependabot state.** Once anyone (or anything — including the flow's own retargeting) edits a Dependabot PR, Dependabot refuses to rebase or recreate it and the PR silently stops tracking new versions. The automation now detects that state and asks Dependabot to recreate the PR fresh. (#175)
- **`deps/` as a first-class branch prefix**, mirroring `chore/` — dependency-bump branches get their own `! deps → next` flow label instead of riding an unrelated prefix. (#178)

## Fixed

- **`compute-highest-commit-type` priority order** — trivial commit types could outrank substantive ones and win the release-PR title; the `TYPE_PRIORITY` order now ranks meaningful types first. (#174)

## Patch releases

None — v4.17.0 is the only release of the 4.17 line.
