# v4.36.3 — 2026-11-13

Patch release that fixes how `sync-release-notes` finds a release's PR. v4.36.2 still reported every release PR as not found on llm-translator, including CLDMV/llm-translator#149, so merged release PR bodies kept their relative links.

## Bug Fixes

- **Release PRs found by their title.** The step looked up a release's PR from its release commit (`GET /commits/{sha}/pulls`). For the bot token that listing gave no usable match, first without `merge_commit_sha` and then without the PR at all. It's no longer used. The step now lists the closed PRs into the default branch once per run and keys the merged ones by the version in their `release: vX.Y.Z` title; if two claim one version, the most recently merged wins. The run log says how many release PRs it found. The test runs against llm-translator's real PR listing. ([#464](https://github.com/CLDMV/.github/pull/464))

## Upgrade notes

- No caller changes needed. Run `sync-release-notes` again in repos that ran it on v4.36.1 or v4.36.2: release bodies are already done, and this run rewrites the merged release PR bodies.
