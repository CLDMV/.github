# v4.16.8 — 2026-07-19

Patch release making the tag-push fallback added in v4.16.7 actually trigger.

## Fixed

- **`fix-orphaned-releases` captures real `git push` stderr.** The shared git helpers stream stderr to the log but never attach it to the thrown error, so the workflow-permission detection added in v4.16.7 only ever saw "Command failed" and the REST fallback never fired. The tag push now runs through `execSync` with captured output, the detection matches against the real git message, and the failure log includes git's rejection text. ([#157](https://github.com/CLDMV/.github/pull/157), released in [#158](https://github.com/CLDMV/.github/pull/158))
