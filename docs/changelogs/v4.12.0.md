Minor release adding two reusable workflows — OpenSSF Scorecard and the master-commit audit — with thin-caller examples.

Scorecard runs the OpenSSF supply-chain checks; the master-commit audit files a deduped issue when a commit lands on the default branch with a subject that doesn't match the release-flow patterns.
