# v4.12.1 — 2026-06-01

Patch release that stops release-PR bodies from listing the same change twice.

## Fixed

- **PR-titled merge commits are dropped from generated release-PR bodies.** The v4 flow merges feature PRs into `next` with merge commits titled like the PR (`feat: … (#N)`), so subject-based merge detection missed them and they appeared alongside their squashed content. Merge commits are now detected structurally by parent count, and `create-release-pr` passes the `base..head` range so the merge filter and patch-id dedup actually run. ([#109](https://github.com/CLDMV/.github/pull/109))
