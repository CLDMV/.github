# v4.27.4 — 2026-09-15

Patch release so a contributor is no longer credited twice in the release `Co-authored-by` trailers when their commits carry different GitHub noreply email forms.

## Fixed

- **Co-author trailers are deduplicated by GitHub login, not raw email.** The ID-prefixed (`{id}+{login}@users.noreply.github.com`) and bare (`{login}@users.noreply.github.com`) noreply addresses identify the same account but were treated as two people, producing duplicate trailers. They now collapse to one entry keyed on the login, preferring the ID-prefixed form for a deterministic result. Non-noreply emails still dedupe on the email itself. ([#296](https://github.com/CLDMV/.github/pull/296))
