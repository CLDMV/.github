# v4.10.0 — 2026-05-29

Minor release adding an optional pre-push container-image scan. Single-feature cut.

## Added

- **Optional pre-push Trivy gate via `enable_container_scan`.** When enabled, a Trivy scan of the built container image runs as a CI gate before publish, failing on findings above the configured severity. Off by default; opt in per repo through the CI entry point (`reusable-container-scan.yml`). (#97)
