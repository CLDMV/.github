# v4.9.0 — 2026-05-28

Minor release adding member auto-merge and the auto-close-linked-issues reminder, with release-PR changelog and title-normalizer fixes.

## Added

- **Auto-merge for org-member PRs to `next` / `hotfixes`.** `member-auto-merge` enables auto-merge on PRs opened by org members against the integration branches, so member contributions flow through the same zero-touch path as bot PRs. (feat: d1801f2)
- **Bootstrap surfaces "auto-close linked issues" as a manual reminder** (the org-level setting isn't API-writable), and defaults a PR-merge commit's title/body to the PR's own title and body. (feat: 62f626e, d902f6e)

## Fixed

- **Release-PR changelogs drop merge commits and correct PR attribution**, simplifying the per-PR group line. (fix: 94218e0)
- **`normalize-pr-title` allows `cldmv-bot`** and picks the chronologically-first commit as the title source. (fix: f329a04)

## Changed

- **CodeQL `js/file-data-to-network-request` suppression rationale extended** in the query-filter docs. (docs: 0e6df9d)
