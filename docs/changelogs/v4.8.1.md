# v4.8.1 — 2026-05-26

Patch release fixing the security-settings diff in org bootstrap.

## Fixed

- **The `saExpected` diff loop compares against the target state.** The `org-bootstrap-repo` action compared each security setting against a hardcoded `"enabled"` rather than the state it was meant to apply, which produced wrong diffs when the target was not `enabled`. It now compares against the target state. ([#68](https://github.com/CLDMV/.github/pull/68), released in [#69](https://github.com/CLDMV/.github/pull/69))
