# v4.40.0 — 2026-11-21

Minor release: the runner image ships tmux, both the distro build and 3.8 at `/opt/tmux-3.8`, so test suites that start private tmux servers can run on cldmv-runners and in k3s-test pods.

## Features

- **tmux in the runner image.** The image had no tmux, so any suite that starts a real tmux server failed before its first test. The distro package (3.4) is now on PATH, and tmux 3.8 is built from the release tarball into `/opt/tmux-3.8` in a separate build stage, pinned by checksum, so the compiler and `-dev` packages stay out of the final image. The build-time gate checks `tmux -V` for both and starts and kills a private server (`tmux -L gate new -d`, `kill-server`) with each, with no `TERM` set. ([#511](https://github.com/CLDMV/.github/pull/511))

## Upgrade notes

- No caller changes. The runner image rebuilds when this release reaches master; tests that need 3.8 call `/opt/tmux-3.8/bin/tmux`, plain `tmux` is 3.4.
