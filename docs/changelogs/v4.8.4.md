# v4.8.4 — 2026-05-26

Patch release so release-PR body updaters no longer overwrite each other's blocks.

## Fixed

- **Any HTML-marker-fenced block in a PR body is preserved.** `update-pr-changelog` now keeps sticky body blocks delimited by HTML comment markers when it regenerates the changelog section, instead of discarding them. ([#75](https://github.com/CLDMV/.github/pull/75), released in [#76](https://github.com/CLDMV/.github/pull/76))
- **Coverage markers renamed from `coverage-badge-*` to `coverage-*`.** `update-pr-coverage` writes the new marker pair and strips any legacy `coverage-badge-*` block, including its separator rule, from in-flight PR bodies so two coverage blocks do not stack. ([#75](https://github.com/CLDMV/.github/pull/75), released in [#76](https://github.com/CLDMV/.github/pull/76))
