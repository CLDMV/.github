# v4.16.0 — 2026-07-09

Minor release closing resolved issues automatically when a release lands, followed by a long run of release-flow, scorecard, and CI hardening patches.

## Added

- **Close resolved issues at release via gh-broker markers.** When a release reaches the default branch, the issues its bundled source PRs marked as resolved (via the gh-broker closing markers) are closed automatically. (#140)
