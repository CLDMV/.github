# v4.6.0 — 2026-05-27

Minor release: org-onboarding auto-discovers the organization's repositories when no explicit list is passed. Single-feature cut.

## Added

- **Org-onboarding auto-discovers org repos when no list is passed.** Running the onboarding fan-out without an explicit repo list enumerates the organization's repositories and applies the matrix to all of them, so a new repo is picked up without editing the caller. (feat: 252e1fd)

## Fixed

- **Grouped the `GITHUB_OUTPUT` writes** in org-onboarding to silence ShellCheck SC2129. (fix: 9bb54b9)
