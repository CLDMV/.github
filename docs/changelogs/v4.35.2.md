# v4.35.2 — 2026-11-03

Patch release with two workflow fixes. Docs-only PRs now skip the test matrix from their first push, and private repos can publish to npm over trusted publishing (OIDC) again because the npm publish jobs run on GitHub-hosted runners.

## Bug Fixes

- **The paths gate diffs feature-branch pushes against their PR base.** A feature branch's first push has a zero `before` SHA, so the gate always fell back to full CI and docs-only PRs never skipped the test matrix. A push to a feature branch is now compared with the branch its PR targets, using the same routing as `feature-pr.yml` (`hotfix/**` to `hotfixes`, the captured prefixes to `next`, anything else to the default branch), falling back to the default branch when that base doesn't exist. That makes every push the PR's own diff, so a docs commit on top of a code commit no longer reads as docs-only. Pushes to `next`, `hotfixes` and the default branch still compare `before..after`. A compare that returns 300 files, the API's cap, now runs full CI because the list may be truncated. Fixes [#423](https://github.com/CLDMV/.github/issues/423). ([#424](https://github.com/CLDMV/.github/pull/424))
- **The npm publish jobs run on GitHub-hosted runners.** npm trusted publishing doesn't work from self-hosted runners, and `publish-npm` and the satellite `publish-extras` job in `reusable-publishing.yml` both defaulted to `cldmv-runners` on private CLDMV repos, so a private repo with no `NPM_TOKEN` couldn't publish. Both jobs now default to `ubuntu-latest` whatever the repo's visibility. The `runs_on` input and the `RUNS_ON_DEFAULT` variable still override it. The jobs only publish the artifact the build job uploaded, so nothing is rebuilt on the hosted runner. `publish-github-packages` authenticates with `GITHUB_TOKEN` and stays on the routed runner. Fixes [#425](https://github.com/CLDMV/.github/issues/425). ([#427](https://github.com/CLDMV/.github/pull/427))

## Upgrade notes

- No breaking changes and no caller changes needed; both fixes ride the `@v4` tag.
- A private repo that set `runs_on: ubuntu-latest` on its publish workflow only to get npm OIDC working can drop that override.
