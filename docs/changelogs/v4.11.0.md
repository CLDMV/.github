# v4.11.0 — 2026-05-29

Minor release adding API-only propagation of issue-closing references and a bootstrap ordering change, with two follow-on patches.

## Added

- **API-only propagation of `Fixes` / `Closes` references.** `sync-closing-issues` copies a source PR's issue-closing references onto the release PR through the API — no branch writes — so the linked issues auto-close when the release reaches the default branch. (feat: 77a9eb1)
- **Org-onboarding bootstraps THIS repo first, then fans out the matrix**, so the org's own `.github` configuration is applied before the org-wide sweep. (feat: 8f07373)

## Fixed

- **Scorecard action pinned to a real version** — replaced the nonexistent `ossf/scorecard-action@v3.4.0` with `v2.4.3`. (fix: df4c623)

## Patch releases

- **v4.11.1** — chore-only batches still trigger release-PR creation (a batch with no feat/fix no longer stalls the release lane); org-onboarding defaults flipped to apply-not-preview with public-only security, and rulesets restrict creations/updates on `master` / `next` / `hotfixes`. (fix: 99cd9d4, chore: edec954, 9904191)
- **v4.11.2** — default `allowed_patterns` in `audit-commit-subject`, so callers can omit the input and inherit the canonical release-flow pattern set.
