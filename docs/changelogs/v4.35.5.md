# v4.35.5 — 2026-11-08

Docs-only patch release. The package layout convention now names the CommonJS test script `test:cjs` and defines `test:dist` as the full test suite run against the build.

## Documentation

- **`test:cjs` and `test:dist` in the package layout.** [package-layout.md](../conventions/package-layout.md) called the script that runs `tests/cjs/entry.test.cjs` `test:dist`, though it only checks the CommonJS entry on the build. That script is now `test:cjs`: the entry check (`dist/index.cjs` loading `dist/index.mjs`) plus any CommonJS-only tests in `tests/cjs/`. `test:dist` now means the whole vitest suite run against `dist/` instead of `src/`. Tests import the package by name, and the vitest config leaves the `<pkg>-dev` condition out for `--mode=dist`, with a resolve test checking the import landed on the right tree ([CLDMV/gitmulti](https://github.com/CLDMV/gitmulti) is the reference). Unbundled builds (tsup `bundle: false`) can instead redirect resolved `src/` paths to `dist/`, which also runs internal-module tests against the build. Fixes [#442](https://github.com/CLDMV/.github/issues/442). ([#443](https://github.com/CLDMV/.github/pull/443))

## Upgrade notes

- No workflow changes. Repos that named the CommonJS entry check `test:dist` should rename it to `test:cjs`.
