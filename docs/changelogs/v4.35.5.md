# v4.35.5 — 2026-11-08

Patch release with one workflow fix and a package-layout update. SLSA provenance attaches again for packages that build in `prepack`, and the package layout convention now names the CommonJS test script `test:cjs` and defines `test:dist` as the full test suite run against the build.

## Bug Fixes

- **Provenance packs without lifecycle scripts.** The subjects job in `reusable-provenance.yml` re-packs the publish run's build artifact with `npm pack`, which runs `prepack` first. The job never installs dependencies, so a package whose `prepack` builds (llm-translator's tsup) failed with `tsup: not found`, the SLSA job was skipped and no `.intoto.jsonl` was attached to the release. Both `npm pack` calls now pass `--ignore-scripts`, the same as the publish side, so the subjects still match the published tarball. Fixes [#444](https://github.com/CLDMV/.github/issues/444). ([#445](https://github.com/CLDMV/.github/pull/445))

## Documentation

- **`test:cjs` and `test:dist` in the package layout.** [package-layout.md](../conventions/package-layout.md) called the script that runs `tests/cjs/entry.test.cjs` `test:dist`, though it only checks the CommonJS entry on the build. That script is now `test:cjs`: the entry check (`dist/index.cjs` loading `dist/index.mjs`) plus any CommonJS-only tests in `tests/cjs/`. `test:dist` now means the whole vitest suite run against `dist/` instead of `src/`. Tests import the package by name, and the vitest config leaves the `<pkg>-dev` condition out for `--mode=dist`, with a resolve test checking the import landed on the right tree ([CLDMV/gitmulti](https://github.com/CLDMV/gitmulti) is the reference). Unbundled builds (tsup `bundle: false`) can instead redirect resolved `src/` paths to `dist/`, which also runs internal-module tests against the build. Fixes [#442](https://github.com/CLDMV/.github/issues/442). ([#443](https://github.com/CLDMV/.github/pull/443))

## Upgrade notes

- No caller changes needed; the provenance fix rides the `@v4` tag. Repos that named the CommonJS entry check `test:dist` should rename it to `test:cjs`.
