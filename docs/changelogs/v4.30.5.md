# v4.30.5 — 2026-10-03

Patch release that stops the CLA bot from recording itself or other bots as signers, and makes ledger commits verifiable again.

## Fixed

- **Bots can no longer be recorded as CLA signers.** `cla-record` had no exemption gate and accepted the required sentence on any line of a comment, so the bot's own request comment, which quotes that sentence, was recorded as the bot signing (on [CLDMV/cpm#40](https://github.com/CLDMV/cpm/issues/40)). It now ignores comments from accounts GitHub reports as a Bot, from logins in a new `exempt_users` input, and any comment carrying the request marker; the reusable's `record` job also skips Bot comments outright. ([#354](https://github.com/CLDMV/.github/pull/354))
- **`cla-check` exempts bot commit authors by account type.** The Copilot coding agent commits as `Copilot`, not `copilot[bot]`, so the login list missed it and the bot asked it to sign. Authors whose account type is Bot are now exempt, and `Copilot` and `copilot-swe-agent[bot]` join the default `exempt_users` list. ([#354](https://github.com/CLDMV/.github/pull/354))
- **Ledger commits are signed again.** GitHub only signs a bot's Contents API commit when the request carries no custom author or committer, so passing the `TAGGER_*` identity made every ledger commit unverified. Ledger writes now go out under the App's own identity. The `TAGGER_NAME` / `TAGGER_EMAIL` secrets remain declared but are ignored, so existing callers keep working. The write-failure comment no longer promises an automatic retry that does not exist. ([#354](https://github.com/CLDMV/.github/pull/354))

## Changed

- **The onboarding fanout template supports a permanent exclude list.** `org-onboarding.yml` reads an optional `data/onboarding-exclude.txt` in the private admin repo and skips those repos in every mode, explicit lists included. The CLA signatures ledger belongs there: the bot writes straight to its default branch, and the code-repo rulesets reject every write. The CLA template, setup guide and ledger seed README now say the ledger must not carry those rulesets. ([#356](https://github.com/CLDMV/.github/pull/356))
