# v4.39.2 — 2026-11-19

Patch release: signed release tags verify again. Since tags started being written with `--cleanup=verbatim`, the PGP signature was glued onto the last line of the tag message, so GitHub showed every signed tag as unsigned.

## Bug Fixes

- **Signed tags show as unsigned.** `--cleanup=verbatim` (added so Markdown headings survive in changelog tag messages) also stops git from adding the final newline. `git tag -s` then appends `-----BEGIN PGP SIGNATURE-----` straight onto the last message line, and neither `git verify-tag` nor GitHub can find the signature. Seen on github-platform v0.1.0. Every tag-message file now goes through a shared `tagMessageText()` helper that ends it with a newline: tag create and update, fix-orphaned-releases, fix-non-bot-tags, fix-orphaned-tags and fix-unsigned-tags. ([#496](https://github.com/CLDMV/.github/pull/496))

- **fix-orphaned-releases temp file.** The tag message was written to a predictable `/tmp/tag-message-<ms>.txt` path, and the cleanup called `require("fs")` inside an ES module, which threw and left the file behind. It now uses a private `mkdtemp` directory under `RUNNER_TEMP`, removed in `finally`. ([#496](https://github.com/CLDMV/.github/pull/496))

## Upgrade notes

- No caller changes. Tags created before this release still carry the glued signature and stay unverified until tag-health re-signs them.
