# v4.39.2 — 2026-11-19

Patch release: signed release tags verify again, and the runner image gains pnpm, yarn and a C/C++ toolchain. Since tags started being written with `--cleanup=verbatim`, the PGP signature was glued onto the last line of the tag message, so GitHub showed every signed tag as unsigned.

## Bug Fixes

- **Signed tags show as unsigned.** `--cleanup=verbatim` (added so Markdown headings survive in changelog tag messages) also stops git from adding the final newline. `git tag -s` then appends `-----BEGIN PGP SIGNATURE-----` straight onto the last message line, and neither `git verify-tag` nor GitHub can find the signature. Seen on github-platform v0.1.0. Every tag-message file now goes through a shared `tagMessageText()` helper that ends it with a newline: tag create and update, fix-orphaned-releases, fix-non-bot-tags, fix-orphaned-tags and fix-unsigned-tags. ([#496](https://github.com/CLDMV/.github/pull/496))

- **fix-orphaned-releases temp file.** The tag message was written to a predictable `/tmp/tag-message-<ms>.txt` path, and the cleanup called `require("fs")` inside an ES module, which threw and left the file behind. It now uses a private `mkdtemp` directory under `RUNNER_TEMP`, removed in `finally`. ([#496](https://github.com/CLDMV/.github/pull/496))

- **pnpm, yarn and native builds in the runner image.** Node 25+ no longer bundles corepack, so the Node 26 runner image had neither pnpm nor yarn, and a k3s-test pod (or any step that skips the package-manager helper) couldn't install a pnpm workspace. The image now installs corepack from npm and runs `corepack enable`, with the download prompt off; each repo's `packageManager` pin still picks the version. It also adds `build-essential` and `python3`, which node-gyp needs for native modules such as node-pty and ssh2's cpu-features (`not found: make`, `Unable to detect compiler type`); hosted ubuntu-latest ships both. The build gate checks pnpm, make, g++ and python3. ([#498](https://github.com/CLDMV/.github/pull/498), fixes [#497](https://github.com/CLDMV/.github/issues/497))

## Upgrade notes

- No caller changes. The runner image rebuilds when this release reaches master. Tags created before this release still carry the glued signature and stay unverified until tag-health re-signs them.
