# v4.45.6 — 2026-11-25

Patch release: publish-time builds can use the build cache.

## CI

- **Build cache through `workflow-publish.yml`.** v4.45.0 added `build_cache_paths` / `build_cache_key_files` to CI, the release-PR workflows and the reusables, but `workflow-publish.yml` didn't declare or forward them, so the publish run rebuilt everything from scratch. It couldn't until those inputs were on `@v4`, because this repo publishes itself through `workflow-publish.yml` and an input the tagged reusable doesn't declare fails the run. It now declares both and passes them to the build-and-test and publish builds. The `core-cicd/publish.yml` example shows them commented out, and `docs/conventions/build-cache.md` lists publish under where the cache applies. Fixes [#552](https://github.com/CLDMV/.github/issues/552) ([#579](https://github.com/CLDMV/.github/pull/579))

## Upgrade notes

- Optional. A repo that already sets the cache inputs in `ci.yml` can set the same values in `publish.yml` so publish builds hit the same cache.
