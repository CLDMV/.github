# v4.24.0 — 2026-09-01

Minor release adding lifecycle status labels to the shared label catalog.

## Added

- **Lifecycle status labels.** The shared label catalog (`data/github-labels.json`) gains a set of lifecycle status labels — `status: not started`, `status: in progress`, `status: implemented`, `status: verified`, and `status: blocked` — so issues and PRs can carry an at-a-glance build/verify state through the flow. They sync to consumer repos through the normal org-label sync. (#251)
