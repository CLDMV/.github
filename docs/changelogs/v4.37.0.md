# v4.37.0 — 2026-11-13

Minor release that lets `sync-release-notes` run against a repository other than the one the workflow belongs to, so one central workflow can re-sync release notes across repos that don't carry their own `sync-release-notes.yml` yet.

## Features

- **`repository` input on sync-release-notes.** The action takes an optional `repository` (`owner/name`). Empty keeps today's behaviour, the repository the run belongs to. A central workflow sets it after checking the target out into the workspace (full history and tags) with an App token scoped to that repo. A value that isn't `owner/name` fails the step before anything runs. ([#469](https://github.com/CLDMV/.github/pull/469))

## Upgrade notes

- No caller changes needed.
