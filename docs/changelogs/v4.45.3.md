# v4.45.3 — 2026-11-25

Patch release: a coverage run whose tests fail still publishes the coverage index and uploads the coverage report.

## Bug Fixes

- **Coverage index and artifact survive a failed test run.** In `reusable-coverage-badge.yml` every step after "Tests + coverage" ran only on success, so a single failing test threw away everything the run had computed: the coverage index on the `badges` branch and the uploaded `coverage` artifact, even though the artifact step's condition was only `upload_coverage_artifact`. The bot token, GPG import, badges-branch push and artifact upload now also run when the tests ran and failed; they still skip when the run is cancelled or an earlier step (install, build, type check) failed. `push-badge` gains a `publish-badge` input, and the workflow passes `false` on a failed run, so the badge keeps its last good value while the index is published with the commit `ci: update coverage index (tests failed)`. The job still fails. Fixes [#565](https://github.com/CLDMV/.github/issues/565) ([#566](https://github.com/CLDMV/.github/pull/566))
