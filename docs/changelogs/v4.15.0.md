# v4.15.0 — 2026-06-21

Minor release giving dependency updates their own changelog section. Single-feature cut.

## Added

- **Dependency updates get their own 📦 Dependencies section** in the generated release-PR changelog, separated from features and fixes so a reviewer can see dependency bumps at a glance. (#134)

## Patch releases

- **v4.15.1** — drop `required_linear_history` from the `hotfixes` ruleset; paired with merge-only it deadlocked native auto-merge on that branch. (#136)
- **v4.15.2** — let bot-merged PRs trigger the release-PR lane. The actor guard previously excluded the bot, so bot-auto-merged PRs never opened the release PR (fatal on `hotfixes`, where every merge is a bot auto-merge). (#138)
