# v4.15.0 — 2026-06-21

Minor release giving dependency updates their own section in the generated changelog. Single-feature cut.

## Added

- **Dependency updates get their own 📦 Dependencies section** in the release-PR / feature-PR changelog. A new `isDependencyUpdate()` detector recognizes Dependabot / Renovate bumps by subject (`chore(deps):`, `fix(deps):`, `bump <pkg> from X to Y`, Renovate's `update dependency <pkg> to vX`), and the changelog generator routes those commits into a dedicated Dependencies section — excluding them from Breaking / Features / Fixes so each bump is listed exactly once. (#134)

## Changed

- **`filterBotCommits` now keeps dependency bumps.** Bot-authored dependency updates are real changelog content, so they're retained even though they're bot-authored; only the release flow's own automation noise (`chore: bump version`, `release:`, merge commits) is dropped. Covered by a new `bot-detection.test.mjs` suite. (#134)

## Patch releases

- **v4.15.1** — drop `required_linear_history` from the `hotfixes` ruleset; paired with merge-only it deadlocked native auto-merge on that branch. (#136)
- **v4.15.2** — let bot-merged PRs trigger the release-PR lane. The actor guard previously excluded the bot, so bot-auto-merged PRs never opened the release PR (fatal on `hotfixes`, where every merge is a bot auto-merge). (#138)
