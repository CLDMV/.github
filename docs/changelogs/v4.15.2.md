# v4.15.2 — 2026-06-24

Patch release letting bot-merged PRs open the release PR.

## Fixed

- **The release-PR lane no longer ignores merges made by the bot.** The next and hotfixes release workflows skipped runs triggered by the bot actor, so a PR auto-merged by the bot never opened or refreshed the release PR. This was fatal on `hotfixes`, where every merge is a bot auto-merge. The actor guard is removed from `local-next-release.yml`, `local-hotfixes-release.yml` and their `release-flow-v4` example templates. ([#137](https://github.com/CLDMV/.github/pull/137), released in [#138](https://github.com/CLDMV/.github/pull/138))
