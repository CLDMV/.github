# v4.3.0 — 2026-05-25

Minor release adding embedded-tests CI integration, the PR-flow label set, and the auto-open-PR-on-push ergonomic — plus a cluster of CodeQL and local-CI fixes shaken out by the new auto-PR machinery.

## Added

- **Embedded-tests CI integration.** CI can fetch and run private test suites from embedded anonymous gitlinks via the org bot App, so proprietary tests exercise the public source without living in the public repo. (feat: 6ab1538)
- **Auto-open a PR on first push to a `feat/`, `fix/`, or `hotfix/` branch.** Pushing a code-side branch opens — and on subsequent pushes refreshes — a PR to the correct v4 integration branch, with a categorized changelog body generated by the shared changelog actions. (feat: 25988b7)
- **PR-flow label set.** The v4 PR machinery applies lane/type labels automatically, so a glance at a PR's badges reveals which integration lane it targets. (feat: 58b1423)

## Changed

- **`fetch-embedded-repos` converted to a `node24` action.** (refactor: 8002a52)

## Fixed

- **CodeQL now runs on the v4 integration branches.** The `pull_request` triggers and the job-level `if` were expanded to cover PRs targeting `next` / `hotfixes`, which previously skipped analysis. (fix: 93729ff)
- **Auto-PR body generation hardened** — the body is generated from the compare API and refreshed on every push, reusing the same categorized-changelog actions as the release-PR flow. (fix: 131de8c, 9f18831)
- **Three local-CI bugs** exposed by the auto-feature-PR commit were corrected. (fix: 1f69e9c)

## Patch releases

- **v4.3.1** — branch-retention now fires on PR-close against the v4 integration branches, so merged feature-branch heads are cleaned up. (fix: 50a68bd)
- **v4.3.2** — CLA check/record rewired for the central ledger (`CLDMV/cla-signatures`): the reusable workflow, the check/record actions, and the example consumer read and write the shared ledger instead of a per-repo `CLA.md`, with a private-ledger seed template under `examples/repo-seeds/.cla-signatures`. (fix: 51b3eda, 794ccdc, b0063c7)
