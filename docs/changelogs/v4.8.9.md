# v4.8.9 — 2026-05-28

Patch release that skips CI when `next` or `hotfixes` is force-synced to `master` after a release.

## Fixed

- **CI short-circuits on a master sync.** After a release, `next` and `hotfixes` are force-synced to `master`, which re-ran the full CI for content that had already passed. A new `master-sync-gate` common step action detects that case, and `local-ci.yml`, `workflow-ci.yml` and the `ci.yml` example template now run it alongside the paths gate. The gates run in parallel under `!cancelled()` so a skipped gate no longer cascades into skipping dependent jobs. ([#87](https://github.com/CLDMV/.github/pull/87))
