# v4.45.5 — 2026-11-25

Patch release: release-merge no longer trips over a stale failed run of a check that has since passed, and docs-only PRs into `next` or `hotfixes` skip CodeQL the same way they skip the test matrix.

## Bug Fixes

- **release-merge judges each check by its newest run.** The commit check-runs API only drops older runs within one check suite, so a check that ran again in a new suite on the same head came back twice. release-merge then saw the old failure next to the fresh pass and refused to merge (a Dependency Review job that had hit the #569 bug, rerun after the fix). It now keeps only the newest run per check name and app (latest `started_at`, then the higher id) before evaluating, which is how branch rulesets read checks too. Fixes [#574](https://github.com/CLDMV/.github/issues/574) ([#575](https://github.com/CLDMV/.github/pull/575))

## CI

- **CodeQL skips docs-only PRs, and only master requires it.** `reusable-codeql.yml` now runs the paths gate on pull requests into `next` or `hotfixes` and skips the analyze job when every changed file is docs. The default globs match `workflow-ci.yml`'s `paths_ignore`, and a new `docs_only_paths` input overrides them per repo, so callers don't need to change anything. Nothing is uploaded on a skip. A skipped analysis leaves a `code_scanning` ruleset rule waiting forever, so the rule moves to the default branch only: the ruleset builders and `data/rulesets/next.json` / `hotfixes.json` drop it from Protect Next and Protect Hotfixes. CodeQL still runs and reports on PRs into `next` that change code, and PRs into the default branch (release PRs), pushes and scheduled runs always analyze. This repo's own `local-codeql.yml` gets the same gate. ([#576](https://github.com/CLDMV/.github/pull/576))

## Upgrade notes

- No caller changes. Existing repos keep the `code_scanning` rule on `next` and `hotfixes` until onboarding runs again, and until then a docs-only PR into `next` waits on code scanning results, so re-run org onboarding (or `v4-bootstrap`) after this release.
