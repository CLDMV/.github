# v4.8.6 — 2026-05-27

Patch release that moves the docs-only filtering in Local CI from the workflow trigger to an inline gate, so the required check always posts.

## Fixed

- **Required PR Check now posts on docs-only changes.** Local CI used trigger-level `paths:` filters, which made GitHub skip the whole workflow for docs-only PRs; the required status never posted and branch protection blocked the merge. The filters were removed and a new `paths-gate` job (backed by a new `paths-gate` common step action) decides whether the heavy validate job runs, while the `Required PR Check` job still reports green for docs-only changes. The reusable CI workflow and the `ci.yml` example template gained the same gate. ([#79](https://github.com/CLDMV/.github/pull/79))
