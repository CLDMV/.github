# v4.13.0 — 2026-06-09

Minor release adding the `type: feature` label and applying it automatically when a PR's range implements a feature.

## Added

- **`type: feature` label, applied automatically when a feature is detected** in a PR's commit range — mirroring the changelog's own "Features" section, so the label and the changelog agree. (feat: 8a4b650)

## Fixed

- **Dropped the ambiguous `patch` alias from `type: bug`.** (fix: 60e04ab)
- **String-safe boolean gates in CI.** The container-scan gate and the coverage-job gates accept `${{ }}`-passed booleans that arrive as the strings `"true"` / `"false"`, so the jobs no longer silently skip. (fix: 10ec6b6, d379f80)

## Patch releases

- **v4.13.1** — trim the `! feature → next` flow-label description under GitHub's 100-char cap, and use `actions/checkout` in the scorecard job (the OSSF step's action allowlist). (fix: 44aeff3, ae7bcd8)
- **v4.13.2** — add the organization profile README. (docs: e3654e0)
