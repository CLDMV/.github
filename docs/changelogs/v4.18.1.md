# v4.18.1 — 2026-08-02

Patch release restoring checkout access on the coverage badge job for private repositories.

## Fixed

- **Coverage badge job can check out private repositories again.** A job-level `permissions:` block replaces the workflow-level one wholesale, so `contents: read` has to be repeated on the badge job in `reusable-coverage-pr-comment.yml`. Without it the job token had `contents: none` and `actions/checkout` failed with `Repository not found` on private repos; public repos read anonymously, which hid the problem until the first private v4 consumer's release PR went red. ([#183](https://github.com/CLDMV/.github/pull/183))
