# v4.33.4 — 2026-10-24

Documentation-only patch that adds the package layout convention for CLDMV JavaScript libraries. No workflow, action or template changed.

## Documentation

- **New convention: library package layout.** [`docs/conventions/package-layout.md`](https://github.com/CLDMV/.github/blob/master/docs/conventions/package-layout.md) sets the source layout every published CLDMV library follows. The code lives in `src/` and tsup bundles it into `dist/`. `src/index.mjs` and `src/index.cjs` are the only entry points, side by side under the same name: no `src/cjs/` folder, no `cjs-shim.cjs`, no `./main` subpath and no self-import by package name. A namespaced `<pkg>-dev` export condition switches a checkout between `src/` and `dist/`, and an unpublished root `devcheck.mjs` (the `@cldmv/uuid` copy is canonical) stops a checkout from silently running the build. The doc covers the `package.json` fields, the tsup config (with `devcheck.mjs` kept external), turning an existing `./main` into a deprecated alias, the vitest and `node --test` wiring, the CI inputs, and a migration table for each layout found across the fleet. `CLDMV/llm-translator` is the reference implementation. ([#391](https://github.com/CLDMV/.github/pull/391))
